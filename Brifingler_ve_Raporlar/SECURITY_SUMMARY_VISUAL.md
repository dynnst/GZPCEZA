## ?? 405/404 vs. 403 Kararý

### Senaryo A: Admin Sayfasýna Student Eriþim
```
ESKI MANTIK (405/404 ile gizle):
GET /AllUsers ? 404 Not Found
? Student: "Admin sayfasý yok mu?"
? Attacker: "Admin sayfasý yok gibi görünüyor"

YENÝ MANTIK (403 ile aç):
GET /AllUsers ? 403 Forbidden
? Student: "Yetkim yok, tamam"
? Attacker: "Sayfayý biliyorlar, sadece yetki var"
```

### Senaryo B: API Call Durumu
```
ESKI (Redirect):
POST /Ajax/SendMessage
? 302 Found (Redirect location: /Giris)
? JavaScript: Confusing, not clear

YENÝ (403 + JSON):
POST /Ajax/SendMessage
? 403 Forbidden
? {"error": "Insufficient permissions"}
? JavaScript: Clear, actionable
```

### ? REKOMENDASYONUMUZ:

```
Strateji: KARMA YAKLAÞIM

1. Admin/Staff Sayfalarý ? 403 Forbidden
   (Sayfa var, yetki yok)

   Örnekler:
   - /AllUsers ? 403
   - /RolYetki ? 403
   - /ErrorLogs ? 403

2. Tamamen Gizli API ? 404 Not Found
   (Sayfa hiç yok, security through obscurity)

   Örnekler:
   - /Internal/BackdoorAPI ? 404
   - /Admin/SecretData ? 404

3. Public Pages ? 200 OK
   - /Home ? 200
   - /Landing ? 200
   - /Kosullar ? 200

4. Login Pages ? Redirect + 401
   - /Giris ? 200 or 302
   - /Home (no token) ? 302 /Giris + 401 if API
```
